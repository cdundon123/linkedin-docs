# Intro fields and profile sections

## Intro fields

Intro fields define the information you enter to display on your profile intro and preview. This is the first information other users visiting your profile will see.

| Field name | Required | Additional details
| --- | --- | --- |
| First name | Yes | |
| Last name | Yes | |
| Additional name | No | |
| Name pronunciation | No | Can only be added in the mobile app |
| Pronouns | No | Visibility of pronouns is customizable |
| Headline | Yes | Text directly below your name that defines your professional identity and value proposition. |
| Current position | Yes | The role title and company you current work at |
| Industry| Yes | The general field of work you are interested in |
| Education | Yes | The university or institution of higher education you attended |
| Country/Region | Yes | |
| Postal code | No | |
| City | Yes | |
| Contact info | No | Profile URL, email, phone number, address, birthday, portfolio |

## Profile sections

Profile sections allow you to display your professional experiences, education, skills, volunteer work, awards, and more to your colleagues. This information is only viewable from your full profile.

All profile sections are optional; however, certain sections (Core and Recommended) should be filled for greater visibility and credibility.

### Core sections

| Section | Description |
|---|---|
| **Education** | Educational institutions you have attended |
| **Position** | Professional roles you have worked |
| **Services** | Professional services you provide |
| **Career break** | Experiences outside a linear career path. For example, maternity leave or sabbaticals. |
| **Skills** | Skills you have acquired |

### Recommended sections

| Section | Description |
|---|---|
| **Featured** | Articles, posts, documents, or other media you are featured in |
| **Licenses & certifications** | Official documents certifying a position, talent, achievements, or educational milestones |
| **Projects** | Projects you have worked on |
| **Courses** | Courses you have taken at an educational institution |
| **Recommendations** | Recommendations from colleagues, mentors, managers, etc. |

### Additional sections

| Field | Description |
|---|---|
| **Volunteer experience** | Volunteer work |
| **Publications** | Articles, books, or other media you have published |
| **Patents** | Patents you have invented |
| **Honors & awards** | Honors and awards you have received |
| **Test scores** | Scores from tests (SAT, APs, LSAT, MCAT, etc.) you have taken |
| **Languages** | Languages you speak, write, and/or read |
| **Organizations** | Organizations you participate in, such as clubs, non-profits, or sports teams |
| **Causes** | Causes you care about |
