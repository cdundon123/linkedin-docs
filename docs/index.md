# LinkedIn: the #1 job-seeking ecosystem

## Overview

This guide outlines steps for using the browser version of LinkedIn: a professional networking platform that allows you to create a professional profile, connect with colleagues, search for jobs, and build industry skills. 

To follow this guide, [sign up for a LinkedIn account](https://www.linkedin.com/signup) or log into an existing one.
