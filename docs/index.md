# LinkedIn: the #1 job-seeking ecosystem

## Overview

This guide outlines steps for using the browser version of LinkedIn: a networking platform that allows you to create a professional profile, connect with colleagues, search for jobs, and build industry skills. 

To follow this guide, [sign up for a LinkedIn account](https://www.linkedin.com/signup) or log into an existing one.

## LinkedIn for job applications

New and experienced users alike can take advantage of LinkedIn's professional development tools to streamline the job search and application process:

- [Set up your profile](apply/set-up-your-profile.md)
- [Add job preferences](apply/add-job-preferences.md)
- [Search for jobs](apply/search-for-jobs.md)
- [Apply for a job](apply/apply-for-jobs.md)
- [Track application progress](apply/track-application.md)
